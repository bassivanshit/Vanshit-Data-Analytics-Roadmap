## 🛠️ Program Architecture

## 🗺️ 15-Week Learning Roadmap

### [cite_start]📍 Phase 1: Foundational Excellence (Weeks 1–3) [cite: 83, 112]
*Focus: Mastering the basics of data manipulation and statistical validation.*
* [cite_start]**W1:** Excel Mastery & Statistical Foundations (KPMG Audit Case) [cite: 83, 114, 115]
* [cite_start]**W2:** Advanced Excel: VBA & Power Query Automation (Deloitte HR Case) [cite: 79, 116, 117]
* [cite_start]**W3:** Statistics & Hypothesis Testing (FMCG Sales Case) [cite: 80, 118, 119]

### [cite_start]📍 Phase 2: The Data Core (Weeks 4–7) [cite: 81, 121]
*Focus: Relational databases, cloud architecture, and complex querying.*
* [cite_start]**W4:** SQL Fundamentals & Relational Design (FinTech Case) [cite: 84, 123, 124]
* [cite_start]**W5:** Advanced SQL: Window Functions & CTEs (Accenture Retail Case) [cite: 84, 125, 126]
* [cite_start]**W6:** BigQuery & Cloud Database Architecture (COVID-19 Global Data) [cite: 84, 127, 128]
* [cite_start]**W7:** SQL Mini-Project & Peer Code Review [cite: 84, 129, 130]

### [cite_start]📍 Phase 3: The Programming Pivot (Weeks 8–11) [cite: 85, 132]
*Focus: Python-driven analytics, Machine Learning, and AI integration.*
* [cite_start]**W8:** Python for Data Analytics: Pandas & NumPy (McKinsey Ops Case) [cite: 85, 134, 135]
* [cite_start]**W9:** Exploratory Data Analysis (EDA) & Visualisation (Banking Risk Case) [cite: 85, 136, 137]
* [cite_start]**W10:** Machine Learning Foundations: Scikit-learn (Accenture HR Attrition Case) [cite: 85, 138, 139]
* [cite_start]**W11:** Prompt Engineering & LLM-Assisted Analytics [cite: 85, 140, 141]

### [cite_start]📍 Phase 4: Visual Storytelling & BI (Weeks 12–15) [cite: 86, 143]
*Focus: C-suite reporting and the Global Capstone Viva.*
* [cite_start]**W12:** Power BI: Executive Dashboards & DAX (NBFC Financial Case) [cite: 87, 145, 146]
* [cite_start]**W13:** Tableau: Data Storytelling & Narrative Design (NGO Global Case) [cite: 87, 147, 148]
* [cite_start]**W14:** Stakeholder Communication & Boardroom Simulation [cite: 87, 149, 150]
* [cite_start]**W15:** **Global Capstone Project & Viva** 🎓 [cite: 88, 151, 152]
